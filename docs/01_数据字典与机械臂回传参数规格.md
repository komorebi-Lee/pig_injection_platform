# 01 · 数据字典与机械臂回传参数规格

> 版本：v1.0　最后更新：2026-09-17
> 对应代码：`backend/app/models.py`（表结构权威来源）、`backend/sql/schema.sql`（自动导出的 DDL）
> 数据库：PostgreSQL 17，schema `public`，17 张业务表

本文回答两个问题：

1. **后端要求机械臂（外包方）回传哪些数据？** —— 第一、二章
2. **这些数据最终落到哪张表、哪个列？** —— 第三、四章

---

## 一、为什么需要这些数据

本项目里后端不是"顺手存一下日志"，而是四件事的唯一负责人：

| 职责 | 说明 | 对应数据 |
|---|---|---|
| 指令出口 | 前端不允许直连机械臂，所有动作经后端下发 | `control_commands` |
| 状态权威 | 任务走到哪一步、机械臂现在什么状态，以后端为准 | `arm_status_samples`、`injection_tasks` |
| 安全与审计 | 谁在何时对哪头猪下发了什么指令、结果如何 | `control_commands`、`manual_control_sessions`、`alarms` |
| 证据留存 | 注射是否成功、打得准不准、猪体温是否异常 | `injection_events`、`thermal_captures`、`media_assets` |

## 二、要求外包方提供的接口与字段（越细越好）

> 这是**索要清单**。拿到外包方文档后，把字段填进 `backend/.env` 的 `ARM_PATH_*` 和
> `backend/app/services/arm_gateway.py::HttpArmAdapter.get_status()` 的映射即可。

### 2.1 心跳 / 状态接口　`GET {ARM_PATH_STATUS}`

**轮询频率：后端每 1 秒调用一次**（可用 `TELEMETRY_INTERVAL_S` 调整）。

| 字段 | 类型 | 必填 | 说明 | 落库位置 |
|---|---|---|---|---|
| `online` | bool | ✅ | 设备在线 | `device_heartbeats.online`、`devices.status` |
| `firmware_version` | str | ✅ | 固件版本，排查"升级后行为变了" | `devices.firmware_version` |
| `uptime_s` | int | ○ | 本次上电运行时长，判断是否异常重启 | `device_heartbeats.uptime_s` |
| `controller_temp_c` | float | ○ | 控制柜/主板温度 | `device_heartbeats.controller_temp_c` |
| `mode` | enum | ✅ | `idle`/`manual`/`auto`/`homing`/`estop`/`fault` | `arm_status_samples.control_mode` |
| `servo_on` | bool | ✅ | 伺服是否使能 | `arm_status_samples.servo_power_on` |
| `estop` | bool | ✅ | 急停是否按下（用于生成 critical 告警） | `arm_status_samples.estop_pressed`、`alarms` |
| `moving` | bool | ✅ | 是否正在运动 | `arm_status_samples.is_moving` |
| `motion_done` | bool | ✅ | 上一条指令是否到位 | `arm_status_samples.motion_done` |
| `speed_override` | float | ○ | 速度倍率 % | `arm_status_samples.speed_override_pct` |
| `safety_state` | enum | ○ | `normal`/`reduced`/`protective_stop`/`emergency_stop` | `arm_status_samples.safety_state` |
| `joints` | float[6] | ✅ | 6 轴关节角（deg） | `arm_status_samples.joint_angles_deg` |
| `joint_velocities` | float[6] | ○ | 各轴角速度 | `joint_velocities` |
| `joint_torques` | float[6] | ○ | 各轴力矩 N·m | `joint_torques` |
| `joint_currents` | float[6] | ○ | 各轴电流 A | `joint_currents_a` |
| `joint_temps` | float[6] | ✅ | 各轴电机温度（≥75 ℃ 自动告警） | `joint_temps_c` |
| `tcp` | `{x,y,z,rx,ry,rz}` | ✅ | 末端位姿，mm / deg | `arm_status_samples.tcp_pose` |
| `tcp_quaternion` | `{qw,qx,qy,qz}` | ○ | 若用四元数则给这个 | `tcp_quaternion` |
| `tcp_velocity` | `{vx,vy,vz}` | ○ | 末端线速度 | `tcp_linear_velocity` |
| **`tcp_force`** | `{fx,fy,fz,tx,ty,tz}` | ✅ | **末端六维力。判断"是否扎到骨头"的关键** | `arm_status_samples.tcp_force`、`injection_tasks.peak_force_n` |
| `tool_frame` / `base_frame` | str | ○ | 坐标系编号，复现轨迹时必需 | `tool_frame` / `base_frame` |
| `payload_kg` | float | ○ | 当前负载 | `payload_kg` |
| `obstacle_avoidance_enabled` | bool | ✅ | 避障总开关 | `arm_status_samples.obstacle_avoidance_enabled` |
| `obstacle_distance_mm` | float | ○ | 最近障碍物距离 | `arm_status_samples.obstacle_distance_mm` |
| `error_code` | str | ✅ | 错误码（稳定枚举，不要用中文句子） | `arm_status_samples.error_code`、`alarms.code` |
| `error_message` | str | ✅ | 人类可读说明 | `arm_status_samples.error_message` |
| `warnings` | str[] | ○ | 非致命告警码列表 | `warning_codes` |
| `queue_len` | int | ○ | 内部指令队列长度 | `queue_len` |
| `active_command_id` | str | ○ | 正在执行的指令号，用于和 `control_commands.arm_command_id` 对账 | `active_command_id` |
| `injection` | object | ○ | 若注射由机械臂内部状态机驱动，见 2.3 | —— |

### 2.2 手动控制接口

| 接口 | 入参（我们下发） | **要求回传** |
|---|---|---|
| `POST {ARM_PATH_JOG}` | `axis`(x/y/z/j1..j6)、`direction`(±1)、`step`、`speed_pct` | `accepted`、`arm_command_id`、`motion_done`、拒绝时给 `error_code` + `message` |
| `POST {ARM_PATH_MOVE_POSE}` | `pose{x,y,z,rx,ry,rz}`、`speed_pct`、`frame` | 同上 + 实际到达位姿 |
| `POST {ARM_PATH_MOVE_JOINT}` | `joint_angles_deg[]`、`speed_pct` | 同上 + 实际关节角 |
| `POST {ARM_PATH_HOME}` | 无 | `accepted`、`homed` |
| `POST {ARM_PATH_STOP}` | 无 | `accepted`、`stopped` |
| `POST {ARM_PATH_ESTOP}` | 无 | `accepted`、`estop_pressed`。**必须幂等，必须无前置条件** |
| `POST {ARM_PATH_ESTOP_RESET}` | 无 | `accepted`、`estop_pressed=false`、`requires_home` |
| `POST {ARM_PATH_SET_MODE}` | `mode`、`origin` | `accepted`、`control_mode` |

**拒答要求**：当处于急停/故障/模式冲突时，必须返回 `accepted=false` + 稳定 `error_code`，
不要静默忽略。后端会据此返回 HTTP 409 给前端。

### 2.3 自动注射接口

| 接口 | 入参 | **要求回传** |
|---|---|---|
| `POST {ARM_PATH_INJECT_START}` | `task_no`、`target_point{x,y,z}`、`depth_mm`、`dose_ml`、`pen_id`、`pig_id` | `accepted`、`arm_task_id`、`phase`、`started_at` |
| `POST {ARM_PATH_INJECT_ABORT}` | `task_id`、`reason` | `accepted`、`aborted` |

注射过程**必须**能回传下列终态数据（后端在流程收尾时读取并写库）：

| 字段 | 类型 | 说明 | 落库位置 |
|---|---|---|---|
| `phase` | enum | `locating`/`aligning`/`inserting`/`injecting`/`retracting`/`completed`/`failed`/`aborted` | `injection_tasks.status`、`injection_events.phase` |
| `actual_entry_point` | `{x,y,z}` | 实际进针点 | `injection_tasks.actual_entry_point` |
| `actual_depth_mm` | float | 实际进针深度 | `actual_depth_mm` |
| `position_error_mm` | float | 目标与实际偏差，**精度指标，答辩要用** | `position_error_mm` |
| `dose_ml` | float | 实际注射量（不是设定量） | `dose_ml` |
| `peak_force_n` | float | 进针阻力峰值 | `peak_force_n` |
| `peak_torque_nm` | float | 峰值力矩 | `peak_torque_nm` |
| `phase_durations_ms` | object | 各阶段耗时 | `phase_durations_ms` |
| `fail_reason` | str | 结构化失败原因码（如 `target_not_found`、`force_exceeded`、`obstacle_blocked`） | `fail_reason` |

### 2.4 自动避障接口

| 接口 | 说明 | **要求回传** |
|---|---|---|
| `GET {ARM_PATH_OBSTACLE}` | 避障实时状态 | `enabled`、`active`、`sensor_type`、`min_distance_mm` |
| 事件推送/轮询 | 一次避障事件 | `obstacle_id`、`distance_mm`、`direction`、`class`、`confidence`、`action_taken`、`speed_before_pct`、`speed_after_pct`、`detected_at`、`cleared_at` |

落库位置：`obstacle_events`（每次"发现→减速/停止/绕行→恢复"记一条）。

### 2.5 热成像接口

| 接口 | 说明 | **要求回传** |
|---|---|---|
| `GET {ARM_PATH_THERMAL}` | 最新一帧测温结果 | 见下表 |

| 字段 | 类型 | 为什么必须要有 | 落库位置 |
|---|---|---|---|
| `emissivity` | float | **没有发射率，温度数值不可复现**（猪体表 0.95–0.98） | `thermal_captures.emissivity` |
| `distance_m` | float | 测温距离影响大气衰减补偿 | `distance_m` |
| `reflected_temp_c` | float | 反射温度补偿 | `reflected_temp_c` |
| `atmospheric_temp_c` / `humidity_pct` | float | 环境补偿参数 | 同名列 |
| `temp_range_min_c` / `temp_range_max_c` | float | 量程，超出量程的读数是无效的 | 同名列 |
| `temp_max_c` / `temp_min_c` / `temp_avg_c` / `temp_center_c` | float | 全幅统计 | 同名列 |
| `matrix_width` / `matrix_height` | int | 原始温度矩阵分辨率 | 同名列 |
| **`body_temp_c`** | float | 猪体表 ROI 平均温度，健康监测主指标 | `body_temp_c` |
| `injected_site_temp_c` | float | 注射点温度，用于判断局部炎症 | `injected_site_temp_c` |
| `ambient_temp_c` | float | 环境温度 | `ambient_temp_c` |
| `rois[]` | array | 每个测温框：`roi_name`、`shape`、`geometry`、`temp_max/min/avg_c` | `thermal_rois` |
| 图像文件 | —— | 伪彩图 / 可见光图 / **16bit 原始温度数据** | `media_assets`（三份都要） |

### 2.6 视觉（如外包方一并提供）

护栏相机给全局定位、臂上相机给局部对位。要求回传：
`camera_role`、`frame_seq`、`class_name`（`pig`/`back_line`/`injection_point`/`needle`/`obstacle`）、
`detected`、`confidence`、`track_id`、`bbox{x1,y1,x2,y2}`、`keypoints`（背脊线）、
`injection_point_pixel{u,v}`、`distance_mm`、图像文件。
落库位置：`vision_detections`。

## 三、数据字典（17 张表）

### 3.1 台账（4 张）

**`pens` 栏位**：`id` / `pen_code`(唯一,如 A-01) / `pen_name` / `barn`(栋舍) / `area_name` /
`capacity` / `guardrail_camera_code` / `arm_camera_code` / `arm_device_code` / `status`
(`active|inactive|maintenance`) / `remark` / `created_at` / `updated_at`

**`pigs` 猪只档案**：`id` / `ear_tag`(耳标,唯一,允许空) / `pen_id`→pens / `breed` / `sex` /
`birth_date` / `weight_kg` / `health_status`(`healthy|abnormal|isolated|treated`) /
`last_injection_at` / `remark`

**`operators` 操作员**：`id` / `username`(唯一) / `display_name` / `role`(`admin|operator|viewer`) /
`password_hash` / `active` / `last_login_at`

**`devices` 设备台账**：`id` / `device_code`(唯一,如 ARM-01) /
`device_type`(`arm|camera_guardrail|camera_arm|camera_thermal|controller`) / `vendor`(外包方) /
`model` / `serial_number` / `firmware_version` / `protocol` / `endpoint` / `mounted_on` / `pen_id` /
`installed_at` / `status` / `last_seen_at` / `remark`

### 3.2 实时状态（2 张，高频写）

**`device_heartbeats` 心跳**：`device_id` / `online` / `latency_ms` / `firmware_version` /
`controller_temp_c` / `uptime_s` / `error_code` / `error_message` / `raw`(JSONB 原始报文) / `sampled_at`
索引：`(device_id, sampled_at)`

**`arm_status_samples` 机械臂遥测**：`device_id` / `control_mode` / `servo_power_on` /
`estop_pressed` / `is_moving` / `motion_done` / `speed_override_pct` / `safety_state` /
`joint_angles_deg` / `joint_velocities` / `joint_torques` / `joint_currents_a` / `joint_temps_c` /
`tcp_pose` / `tcp_quaternion` / `tcp_linear_velocity` / `tcp_force` / `tool_frame` / `base_frame` /
`payload_kg` / `obstacle_avoidance_enabled` / `obstacle_distance_mm` / `error_code` / `error_message` /
`warning_codes` / `queue_len` / `active_command_id` / `raw` / `sampled_at`
索引：`(device_id, sampled_at)`、`(sampled_at)`

### 3.3 指令与审计（2 张）

**`control_commands` 指令审计**：`request_id`(UUID,唯一,**幂等键**) / `device_id` / `operator_id` /
`task_id` / `command_type` / `source`(`web|api|system|local`) / `client_ip` / `payload` /
`result`(`pending|running|success|failed|rejected|timeout`) / `accepted` / `reject_reason` /
`arm_command_id` / `error_code` / `response` / `duration_ms` / `created_at` / `completed_at`

**`manual_control_sessions` 手动会话**：`session_id`(UUID) / `device_id` / `operator_id` /
`operator_name` / `client_ip` / `started_at` / `ended_at` /
`end_reason`(`normal|estop|timeout|disconnect|auto_takeover`) / `jog_command_count` /
`max_speed_pct` / `estop_triggered` / `remark`

### 3.4 注射主线（2 张）

**`injection_tasks` 注射任务**（一次注射一行，成功失败都留档）

- 标识：`task_no`(唯一,`T20260917-0001`) / `batch_no` / `device_id` / `pen_id` / `pig_id` / `ear_tag_snapshot`
- 人员模式：`operator_id` / `operator_name` / `mode`(`auto|manual`)
- 状态：`status`(`created|queued|locating|aligning|inserting|injecting|retracting|completed|failed|aborted`) / `fail_reason` / `fail_message`
- 目标：`target_source` / `target_point_base` / `target_point_pixel` / `target_confidence` / `target_depth_mm` / `target_angle_deg`
- 实际：`actual_entry_point` / `actual_depth_mm` / `actual_angle_deg` / `position_error_mm`
- 耗材药品：`needle_id` / `drug_name` / `drug_batch_no` / `dose_target_ml` / `dose_ml`
- 力学温度：`peak_force_n` / `peak_torque_nm` / `body_temp_c` / `ambient_temp_c`
- 时间：`started_at` / `finished_at` / `duration_ms` / `phase_durations_ms`
- 其它：`obstacle_triggered` / `retry_count` / `raw`

**`injection_events` 过程时间线**：`task_id` / `event_type`
(`phase_change|needle_insert|drug_inject|needle_retract|force_sample|vision_detect|obstacle_hit|thermal_sample|alarm|abort|error`) /
`phase` / `message` / `payload` / `occurred_at`

### 3.5 感知（5 张）

**`vision_detections`**：`device_id` / `camera_role`(`guardrail|arm`) / `task_id` / `frame_seq` /
`class_name` / `detected` / `confidence` / `pig_id` / `track_id` / `bbox` / `keypoints` /
`injection_point_pixel` / `distance_mm` / `image_asset_id` / `raw` / `captured_at`

**`thermal_captures`**：见 2.5 全部字段 + `capture_no` / `frame_seq` / `is_fever` /
`thermal_asset_id` / `visible_asset_id` / `raw_asset_id` / `raw` / `captured_at`

**`thermal_rois`**：`thermal_capture_id` / `roi_name` / `shape` / `geometry` / `temp_max_c` /
`temp_min_c` / `temp_avg_c`

**`obstacle_events`**：`device_id` / `task_id` / `event_type`
(`detected|slowdown|stop|reroute|cleared`) / `sensor_type` / `obstacle_distance_mm` /
`obstacle_direction` / `obstacle_position` / `obstacle_bbox` / `obstacle_class` /
`detection_confidence` / `point_cloud_asset_id` / `action_taken` / `speed_before_pct` /
`speed_after_pct` / `resumed` / `detected_at` / `cleared_at` / `duration_ms` / `raw`

### 3.6 媒体与告警（3 张）

**`media_assets`**：`asset_type`(`image|video|thermal_raw|depth|log|other`) /
`category`(`injection_evidence|thermal|obstacle|snapshot|recording|needle|calibration`) /
`task_id` / `device_id` / `file_path` / `file_name` / `mime_type` / `file_size_bytes` / `width` /
`height` / `duration_ms` / `checksum_sha256` / `captured_at` / `remark`

**`alarms`**：`alarm_no`(唯一,`AL20260917-0001`) / `device_id` / `task_id` /
`level`(`info|warning|critical`) /
`category`(`estop|obstacle|temperature|injection_failed|communication|needle|drug|system`) /
`code` / `title` / `message` / `value` / `threshold` /
`status`(`active|acknowledged|cleared`) / `acknowledged_by` / `acknowledged_at` / `cleared_at` / `asset_id` / `raw`
> 同类告警 60 秒内自动去重（`services/alarms.py::DEDUP_WINDOW_SECONDS`），避免机械臂持续报同一个错把表刷爆。

**`system_events`**：`event_type` / `level` / `source` / `message` / `detail` / `occurred_at`

## 四、数据量与保留策略

| 表 | 写入频率 | 单日行数（按 8 小时作业） | 默认保留 |
|---|---|---|---|
| `arm_status_samples` | 1 条/秒 | ≈ 28,800 | 30 天，`POST` 清理见 `TelemetryPoller.purge_old_samples()` |
| `device_heartbeats` | 1 条/秒 | ≈ 28,800 | 30 天 |
| `thermal_captures` | 1 条/秒 | ≈ 28,800 | 长期（体积小） |
| `obstacle_events` | 事件驱动 | 视现场 | 长期 |
| `control_commands` | 操作驱动 | 数百~数千 | 长期（审计，不可删） |
| `injection_tasks` / `injection_events` | 每头猪一次 | 数百 | **永久保留** |
| `media_assets` | 任务驱动 | 每头猪 2–5 张 | 按磁盘容量滚动 |

> 高频表已建 `(device_id, sampled_at)` 索引。单任务到数千头猪时，建议把
> `arm_status_samples` 改为按月分区或改用 TimescaleDB，**当前规模不需要**。

## 五、向外包方索要的清单（可直接发给他）

1. 状态查询接口的完整字段表 + **错误码枚举表**（含每个码的触发条件与恢复方法）。
2. 手动控制类接口的入参/出参，特别是**拒绝执行时的响应格式**。
3. 急停接口：确认它是否**幂等**、是否**无前置条件**、是否需要单独的心跳保活。
4. 自动注射：`phase` 的取值集合、各阶段超时时间、终态必回字段（尤其 `actual_depth_mm`、
   `position_error_mm`、`peak_force_n`）。
5. 自动避障：障碍物类别枚举、动作枚举、事件是推送还是轮询、是否带点云/深度图。
6. 热成像：发射率/距离/反射温度是否可回传，原始 16bit 温度数据能否一并输出。
7. 通讯方式（HTTP / WebSocket / Modbus-TCP / ROS2）、鉴权方式、并发上限、心跳超时定义。
8. **坐标系定义**：base 与 tool 的原点、朝向、单位（mm 还是 m，deg 还是 rad）。
9. 一份可用的**联调环境**（哪怕只是固定返回值的 Mock 服务），用于我们在真机到位前打通链路。
